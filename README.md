# Real-Time Chat App

This is a simple real-time chat application made with React and Socket.IO.

## Features

* Login with a username
* Send messages in real time
* Messages appear without refreshing
* Previous messages are saved
* Shows message time
* Shows online/offline status
* Shows last seen
* Edit messages within 5 minutes
* Works on mobile and desktop

## Technologies Used

* React
* Vite
* JavaScript
* CSS
* Socket.IO

## How to Run

Clone the project:

git clone https://github.com/swetasm108-bit/ChatFrontend.git

Go to the project folder:

cd ChatFrontend

Install the packages:

npm install

Start the project:

npm run dev

Open:

http://localhost:5173

## Environment Variables

No environment variables are needed for the frontend.

The frontend connects directly to the deployed backend.
